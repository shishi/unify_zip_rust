       .ZIP ファイルの解凍をウィンドウズ上で！

                           UNZIP32.DLL 開発用SDK Ver 0.77β3
---------------------------------------------------------------------------- 


０．はじめに

    このたびは「UNZIP32.DLL」をダウンロードして頂きありがとうございます。

    これは、ZIP ファイルの解凍を実現するＤＬＬ（ライブラリ）です。32ビット版
    ですので、Windows 95 または Windows NT（i386用）でのみ動作可能です。
    単独で使用することはできません。対応したアプリケーションが必要です。

    一応これはSDKと言う事で、開発用のパッケージになってますが、β版と言う事で
    DLL 単独での他のフォーラムへの掲載はありません。

    また、現在 NIFTY-Serve FWINDC MES #3 にて進行中の『統合アーカイバ
    ＡＰＩ仕様』（この名称も私が勝手に付けただけ ^_^、まだ決まってません）
    に準拠しています（最終的には、ね ^_^）。
    なお、「ＡＰＩ仕様」は現在進行形のプロジェクトです。したがって、この
    UNZIP32.DLL に含まれる機能も、最終決定版ではないと言うことを充分に認識の
    上、ご使用ください。

    それから貴方のソフトでこのＤＬＬに対応する場合、出来るだけダイナミック
    リンク（LoadLibrary/GetProcAddress）で使用するようにして、UNZIP32.DLL が
    無い環境でも、（ZIP関係が使えないだけで）問題なく動作するような設計にして
    ください。

    このバージョンでは、まだ 16ビット版 UNZIP.DLL と同じ API しか実装してません。
    また、色々と問題あり、ですがとりあえずの中間報告としてご覧ください。
    すでに、Ｍｉｃｃｏさん作の DMZIP32.DLL に対応したプログラム（ソース）をお持ち
    の方は、そのまま置き換えるだけで使えると思いますので、試してください。

    16ビット版 UNZIP.DLL Ver 0.65αからは、一から書き直してますので、UNZIP.DLL で
    問題なかったからと言って安心しないで厳しい目でチェックしていただければ幸いです。

    機能追加と変更：
        16ビット版に対し UnZipSetOwnerWindowEx 系のAPIだけが追加されてます。
        また、一部のオプションが変更／廃止になったりしてますので注意してください。

    β１からの変更：
        UnZipCheckArchive() でロングファイル名対応が不完全だった問題。
        UnZipConfigDialog() のバグフィックス。

    β２からの変更：
        UnZipConfigDialog() をある条件で呼ぶと、それ以後ビジーのままになってた。
        レジストリーのキー名が UNZIP32 ではなく、UNZIP になっていた。


１．ファイルについて

    UNZP32B3.LZH を解凍すると以下のファイルが得られます。

    UNZIP32.TXT  : このドキュメントです。

    UNZIP32.DLL : ライブラリ本体（DLL 版の UNZIP）です。
    UNZIP32D.TXT: UNZIP32.DLL でのコマンド等についての説明ファイルです。

    UNZIP32.API : UNZIP32.DLL で使用できるＡＰＩの説明書です。
    UNZIP32.H   : UNZIP32.DLL を使用するためのヘッダーファイルです。
    UNZIP32.LIB : UNZIP32.DLL を使用するためのライブラリです。
                  なおこれはＶＣ＋＋用ですので、ＢＣ＋＋等では使用出来ません。
                  また上記にも書いたように、出来ればこれは使わずにダイナミック
                  にリンクする方法をお取りください。
    UNZIP32.INF : .ZIP に関連付けられたアプリが無い環境で、とりあえず UNZIP32.DLL
                  を使えるようにする設定ファイルです。
                  エクスプローラの右メニューでこのファイルを「インストール」
                  すると、右メニューに「UNZIP32: ここで解凍(&Z)...」と言う項目
                  が追加されます（\Windows\System\ へのコピーも行います）。
                  この項目を選択すると、その場で解凍が始まります。
                  すでに .ZIP に別アプリが関連付けられていると、その設定が消え
                  ますので注意してください。


２．使い方

    これはライブラリのみですので、単独では使用できません。どうしても単独で
    使いたい場合は、上記の UNZIP32.INF の説明をご覧ください。

    A. プログラムから
        API については，UNZIP32.API をご覧ください。
        UNZIP32.DLL を使用するには UNZIP32.H をインクルードし、リンク時に
        UNZIP32.LIB をリンクするか、LoadLibrary()/GetProcAddress() により
	ダイナミックにリンクすることが必要です（出来るだけこちらの方法を）。

    B. 一般ユーザーから
         このＤＬＬを使用するためには、対応したアプリケーションが必要です。
        『UNZIP32.DLL Ver 0.7x 以上に対応』と明記されたアプリケーションをご使用
         ください。

         このＤＬＬはウィンドウズのディレクトリ（通常は \Windows\system\）に
         コピーしてお使いください。

    多数の方達が単独または共通で保有しています。
